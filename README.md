# Wi-Fi-Network-Discovery-and-Configuration-Monitoring-with-M5Stack

A portable wireless network discovery and security monitoring project developed using an ESP32-based M5StickC PLUS2 and Arduino IDE.

I recently participated in an ethical hacking masterclass in the University of Cumbria where we created a wardriver, so I wanted to use what I had learned to create a similar tool.

This project explores wireless network security, ESP32 development and embedded systems programming.

The device uses passive Wi-Fi scanning to discover nearby access points without connecting to them or attempting authentication.

## Hardware and Software used

- M5StickC PLUS2 (ESP32)
- USB-C data cable
- Windows PC for development and analysis
- Arduino IDE
- C++
- ESP32 Wi-Fi library
- M5StickC PLUS2 library

## Current Features

### Passive Wi-Fi Discovery

- Button-controlled Wi-Fi scanning.
- Passive wireless network discovery.
- Filtering for an authorised test network. (my network)
- SSID andd BSSID identification
- Wi-Fi channel detection.
- RSSI measurement.
- Basic open/encrypted security classification.
- Serial Monitor output.



## Responsible Use

This project is intended for educational and defensive security research.

Scanning and analysis are restricted to authorised environments. The device does not attempt to access networks, capture credentials or bypass authentication.
